(`mcp-server/tools/add_expense.py`, `get_budget_status.py`,
`monthly_summary.py`, `list_expenses.py`), each an httpx call to ONE frozen

the exact request shape (path, method, Authorization header, JSON body) are
all EXECUTED on this host. No live server, no egress, no browser.
