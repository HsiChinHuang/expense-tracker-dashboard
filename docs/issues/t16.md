## Goal

Build the frontend data layer for the three new resources on the merged t9
client: typed `api/categories.ts`, `api/expenses.ts`, `api/budgets.ts` mapping
1:1 to the merged Chapter 7 endpoints (money typed as strings, dates as
`YYYY-MM-DD` strings); a `queryKeys` factory; TanStack Query hooks
(`use_categories`, `use_expenses` with filter params, `use_expense_mutations`,
`use_budget`, `use_budget_mutations`, `use_create_category`,
`use_delete_category`) implementing the REQ-FE-051 invalidation matrix; and
MSW handlers for every phase_3 endpoint so t17/t18 and this issue's own tests
run fully in jsdom. No page or form UI here.
