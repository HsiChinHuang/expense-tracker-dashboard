## Pinned decisions (groom rulings resolving survey open questions)

1. **percentage wire type**: JSON number (float) or `null` — `null` iff budget is 0. Money fields are
   2-dp strings; percentage is NOT a string (Chapter 7 examples `87.5`, `62.5`).
2. **months bounds 1..24 default 6** per Chapter 7 §7.7.3. (The phase brief said "6..24" — the frozen
   chapter says minimum 1; the chapter wins. Flagged for the orchestrator.) weeks 1..52 default 12,
   limit 1..50 default 10, both `Query(type=int)` → FastAPI yields the merged 422 shape for non-integers.
3. **year_month**: missing/malformed → 422 `{detail, code: VALIDATION_ERROR, field: null}`; reuse the
   merged `budget_service.validate_year_month` (raises `AppError` with `code="VALIDATION_ERROR"`).
4. **is_over_budget** = `total > budget AND budget > 0`; **remaining** = budget − total, may be negative,
   formatted `f"{q:.2f}"` (e.g. `"-150.25"`).
5. **trend item keys** `{year_month, total}` — no `label` field. **by-category top level** `{year_month, total, categories}`.
6. **Determinism pin**: `get_trend` and `get_heatmap` accept an optional keyword `today: date | None = None`
   (default `date.today()`); service tests pass `today=` explicitly. Additive to Chapter 6's signatures.
7. **recent items** reuse the merged 10-key expense wire shape (same keys/semantics as
   `ExpenseResponse.from_expense`); the Builder may import the merged helper or build `ExpenseResponse`
   directly inside `DashboardRecentResponse`.
8. **No new Alembic revision** (heads stay `005`; this card touches no models) and **no new Python
   dependency** (runtime deps stay 10).
9. **float() scope (groom ruling after measuring the naive gate)**: money fields stay Decimal end to end
   and are serialized as 2-dp strings; `float(...)` is permitted **only** for the percentage display
   conversion (`round(float(total / budget * 100), 1)`), exactly as Chapter 6 §6.10.1 pseudocode shows.
   A blanket `! grep "float("` gate is **unsatisfiable** and was rejected: Pydantic v2 serializes `Decimal`
   to a JSON *string*, so a Decimal-only percentage would break the frozen number-or-null wire type (ruling 1),
   and a Decimal-typed percentage also breaks the frozen test arithmetic (`abs(sum(...) - 100.0)`).
   Money correctness is enforced by the 2-dp string assertions in ac2/ac3/ac4, not by a grep.
   The ac5 gate is therefore `grep -q "from decimal import Decimal"` (positive) plus the negated
   DB-date-function grep (ruling 4), each preceded by `test -f` so the negation is non-vacuous.
10. **Router shape**: `response_model` is optional for these endpoints (the merged expenses router uses
    it; returning a plain dict is acceptable) — the frozen contract is the observable JSON key set, which the
    integration tests pin. The `today=` determinism kwarg is passed positionally or not at all from the router.
