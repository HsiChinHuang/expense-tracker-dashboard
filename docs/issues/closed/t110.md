## Context

**The measured hosted defect (D2).** On the hosted app
(`https://expense-tracker-dashboard-1qtu.onrender.com`, deployed from main tip
`cd0bf50`), `create_app` registers a `GET /` handler returning `{"status": "ok"}`
BEFORE the SPA catch-all, so a visitor at the bare root URL receives a JSON payload
instead of the application. The operator opened the deployed URL, saw JSON, and
reasonably concluded the site was broken. `/api/v1/health` is unaffected and answers
correctly. This card makes the root serve the built SPA when a built frontend is
present, while the JSON status payload stays reachable where it is load-bearing.

**THE DECISION THE OPERATOR ASKED TO BE RULED ON AND RECORDED: what does `GET /`
return in the route-free (local development / committed-tree) case? RULING: it keeps
returning `{"status": "ok"}`.** Recorded reasoning:

1. `backend/tests/unit/test_smoke.py` (t1) asserts `client.get("/").json() ==
   {"status": "ok"}` on the committed tree, and leg 8 (t1, 0-based index into the
   `tests` array) runs that whole file in every merge sweep. The payload is
   load-bearing on a leg this card does not own.
2. The committed tree has no built frontend to serve there, so "serve the SPA" has
   no meaning locally; inventing one would mean committing build output, which the
   route-free premise forbids.
3. Scoping the change to the static-present case is what makes the FROZEN
   assertions survive WITHOUT any written amendment: `paths.count("/") == 1`
   (leg 130, t24) and "an unknown path answers 404" (leg 130, t24) both stay true
   because the fix changes what the ONE existing root route RETURNS, never how many
   routes exist. **No written amendment to a frozen assertion is needed or made by
   this card, and that is a deliberate design constraint on the fix, not an
   accident.**

**The shape the fix must take (measured constraints, not preferences).** A
`FileResponse` cannot be returned from a handler annotated `-> dict[str, str]`
without FastAPI deriving a response model, and the options were measured on a
throwaway clone:

- Widening the annotation to `dict[str, str] | FileResponse` needs
  `response_model=None`, which CHANGES the generated schema for `/` (the
  `Response Read Root Get` model disappears) and therefore regenerates
  `openapi.yaml` - which is byte-pinned by leg 227 (t59, 0-based index 227) and
  compared for path parity by `OPENAPI_PARITY`. Rejected.
- The shipped shape is therefore: keep the `@application.get("/")` decorator, the
  `-> dict[str, str]` annotation, the docstring and the `operationId` EXACTLY as
  they are, return the built `index.html` as a `FileResponse` when
  `resolve_static_dir() / SPA_INDEX_FILE` exists, else the status dict. The
  `-> dict[str, str]` annotation is then a lie to mypy-strict, and the single
  sanctioned repair is one `# type: ignore[return-value]` on that return (the repo
  already carries two `type: ignore[import-untyped]` precedents in
  `backend/scripts/`). The comment above the handler must state WHY the annotation
  and docstring are frozen: `openapi.yaml` carries this route's `summary` and
  `description` verbatim, so the prose is contract and may not be improved.
  Measured on the clone: `ruff` clean, `mypy --strict` clean, `GET /` -> 200
  `text/html` with a staged tree, and the runtime schema for `/` byte-identical to
  the frozen `openapi.yaml` block.
