## Goal

Ship the dashboard page and its two remaining UI pieces: a reusable
`MonthPicker` (prev/next arrows + accessible month label driven by MonthContext,
shared vocabulary with the merged budget-page picker but a NEW component —
merged pages are not refactored) and `BudgetProgress` (the fifth "chart", a
pure div progress bar per REQ-FE-074). `dashboard_page.tsx` mounts at "/"
inside ProtectedRoute, consumes the six t20 hooks (six parallel requests,
REQ-ARCH-032), renders the header (logo, MonthPicker, user menu), four KPI
cards (total spent, budget, remaining, transactions), the five charts from
t21 + BudgetProgress, and the recent-transactions list. Month switch flows
through MonthContext so all six queries move together; rapid switching must
settle on the latest selection.
