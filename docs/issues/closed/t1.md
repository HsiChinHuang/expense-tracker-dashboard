## Goal

Initialize the FastAPI backend project under `backend/` with uv-managed
dependencies, a minimal app factory, a placeholder smoke test, and lint/type
configuration, so `uv sync`, `uv run pytest`, `uv run ruff check .`, and
`uv run mypy .` all succeed.

## Verification commands

- ac1: `bash -c 'cd backend && test -f pyproject.toml && grep -Eq "requires-python *= *\"[^\"]*3\.12" pyproject.toml && for p in fastapi uvicorn sqlalchemy alembic pydantic python-jose passlib httpx pytest-cov pytest-asyncio pytest ruff mypy; do grep -qi -- "$p" pyproject.toml || exit 1; done && test -f uv.lock'`
- ac2: `bash -c 'export PATH="$HOME/.local/bin:$PATH"; command -v uv >/dev/null || exit 1; cd backend && uv sync >/dev/null 2>&1'`
- ac3: `bash -c 'export PATH="$HOME/.local/bin:$PATH"; command -v uv >/dev/null || exit 1; cd backend && test -f app/main.py && grep -Eq "def create_app" app/main.py && grep -Eq "^app *= *create_app" app/main.py && uv run pytest tests/unit/test_smoke.py -q >/dev/null 2>&1'`
- ac4: `bash -c 'export PATH="$HOME/.local/bin:$PATH"; command -v uv >/dev/null || exit 1; cd backend && out=$(uv run pytest -q 2>&1) || exit 1; echo "$out" | grep -Eq "[1-9][0-9]* passed"'`
- ac5: `bash -c 'export PATH="$HOME/.local/bin:$PATH"; cd backend && uv run ruff check . >/dev/null 2>&1 && uv run mypy . >/dev/null 2>&1'`

All commands run from the repository root. `export PATH="$HOME/.local/bin:$PATH"`
makes the Linux `uv` binary (installed at `~/.local/bin/uv` in the WSL toolchain)
resolvable; `command -v uv || exit 1` turns a missing toolchain into a clear
fail rather than a 127 from a nested shell.

## Context

This issue is the backend half of the phase_1_init skeleton milestone
(`docs/plan.md` § phase_1_init, second issue template). t0 established the
Chapter 16 directory tree with placeholder-only files; t1 turns `backend/`
into a working uv project so that every later backend issue (t3 health
endpoint, phase_2 auth, phase_3 CRUD) can build and test inside it. It
implements the tech-stack requirements of requirements/Chapter3_TechStack.md
§3.2 (FastAPI/uvicorn/SQLAlchemy/Alembic/Pydantic 2/python-jose+passlib/httpx/
pytest/ruff/mypy) and §3.9 (REQ-TECH-080 pinning via `pyproject.toml` +
committed `uv.lock`), and satisfies the "backend starts with passing tests"
half of REQ-PLAN-012. Contract-first verification applies
(`contract_first.require_for` includes `backend`), hence every AC has a
runnable command. Environment note: on the WSL host `uv` lives at
`~/.local/bin/uv` and is not on the default PATH, which is why the
verification commands prepend it.
