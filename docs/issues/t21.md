## Goal

Execute the survey's recharts admission (the package.json diff is owned SOLELY
by this issue) and ship the four chart components under
`frontend/src/components/charts/` with RTL+MSW tests: `category_pie_chart.tsx`
(Recharts PieChart, top-6 + Other merge, API colors), `monthly_trend_chart.tsx`
(Recharts BarChart, stdlib "MMM YY" labels, #3B82F6), `cumulative_line_chart.tsx`
(Recharts LineChart + dashed ReferenceLine at budget, red stroke when over
budget), and `weekly_heatmap.tsx` (custom div/table grid per REQ-FE-073 —
deliberately NOT Recharts). Each component takes plain data props (no query
calls inside) so t22 wires them to t20 hooks, and each renders the t20
EmptyState when its dataset is empty.
