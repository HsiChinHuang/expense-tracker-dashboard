  `change-me-locally` compose placeholders, and the README says plainly that
  this stack is LOCAL-ONLY and is never exposed to public traffic.

  This card therefore ships configuration plus a README that states the start
  command; it does not claim a measured live stack, and it does not write a
  PASS anywhere about a container it did not run.
- YAML style: 2-space indent, `true`/`false` only, `#` comments with one
  space. Images are pinned by tag (no `latest`).
- No dependency additions anywhere; no backend/frontend/product-code change;
  `openapi.yaml` untouched (contract_first carve-out lives in t78's text).
