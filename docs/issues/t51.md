## Goal

Land the four remaining Chapter 15 technical documents so the documentation map
of REQ-DOC-002 is complete. Each is written against the MERGED code, not against
an ideal: `docs/architecture.md` restates the shipped layering with an ASCII
diagram and the real decisions (SQLite-first with the PostgreSQL timeout chain
and fallback, same-transaction audit logging, SPA-served-by-FastAPI, verbatim
money strings); `docs/api.md` documents the real base URL, the bearer-token
contract, the pagination envelope, the error-code vocabulary and the endpoint
reference generated from the merged routers; `docs/design-system.md` documents
the real Tailwind tokens, chart colors and states found in the merged frontend;
`docs/testing-guidelines.md` documents the real test layers (backend
unit/integration counts, frontend vitest/MSW, E2E Playwright, the coverage
targets, the naming rules from docs/coding_standards.md) and what the project
deliberately does not test.
