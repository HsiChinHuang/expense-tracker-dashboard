## Context

Root cause (t38-groom-measured, re-measured by this groom at the base commit): semgrep 1.180.0 refuses `--config auto` combined with the explicit CLI flag `--metrics off` ("Cannot create auto config when metrics are off"); Makefile line 123 passes exactly that flag, so the target exits rc=2 deterministically in ~2s without producing a report.
