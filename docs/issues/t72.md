## Goal

An operator who clones this repository and follows README Quick Start verbatim
must reach a running app. Four approved, operator-reported defects are fixed in
ONE card because all four live in the same file and land on the same measured
digest:

1. Quick Start never installs dependencies. `npm run check` is step 1 and every
   ROOT npm script invokes `tsx`, a ROOT dependency, so on a fresh clone the
   very first command dies. Add an explicit `npm install` step at the repo root,
   once, before any `npm run` command.
2. The `.env` step is mis-located and overstated. Keep the step, mark it
   OPTIONAL for offline local mode, and state honestly what needs it and what
   does not, including the root-vs-`backend/.env` location mismatch.
3. Add a `## Troubleshooting` row for the tsx symptom.
4. Strengthen the `seed:demo` instructions: run it in a SECOND terminal while
   `npm run dev` keeps running, no dev restart is needed, nothing visible
   changes in the terminal afterwards, and the demo data appears only in the
   browser after signing in as `demo@example.com` - logging out first if the
   operator is already signed in as their own account.

The card also performs the SINGLE pin-5 switchover, because the README digest
and line count move as a consequence of the edits.
