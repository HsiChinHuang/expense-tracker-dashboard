## Goal

Give the backend a real metrics substrate so that the alert rules in
`observability/alerts.yaml` read measured numbers rather than invented ones: an
OpenTelemetry SDK setup with a Prometheus exporter, the three resource
attributes that make a series attributable, and a `/metrics` endpoint that is
reachable from localhost and never from public traffic.

## AC draft (groom will fence these - target 5 fenced ACs, inside max_acs=6)

- **ac1 - the substrate module exists, is typed, and initialises once.**
  `backend/app/telemetry.py` exists, passes mypy strict and ruff, exposes a
  documented setup function, and configures the Resource with
  `service.name`, `deployment.environment` and `service.version`. The fence
  greps the three attribute keys and runs `uv run mypy` + `ruff check` on the
  touched files.
- **ac2 - /metrics is served and carries the resource attributes.** A pytest
  leg (TestClient/httpx, no live server, no network) asserts `GET /metrics`
  returns 200 and its body carries the three resource-attribute values. This
  is the difference between a substrate and an attestation.
- **ac3 - the endpoint is local-only, by a NAMED mechanism.** The card states
  the mechanism it used (the candidate list, in the card's own words: bind the
  metrics mount so it is only reachable on loopback, and/or gate the mount on
  the merged `ENVIRONMENT`/settings so a production-configured app does not
  serve it - the card picks ONE and names it in the text) and a fence proves
  it: with the production-flavoured setting the route is absent, with the
  development default it is present. The fence also asserts the mechanism is
  documented in the module docstring.
- **ac4 - openapi.yaml is untouched and the exemption is recorded, not
  silently applied.** A fence asserts `openapi.yaml` is byte-clean against the
  base AND that `/metrics` appears in it ZERO times AND that the card text
  contains the exemption sentence. The point of the leg is that the exemption
  is a documented decision, not an accident of the contract generator.
- **ac5 - zero behaviour drift plus delta purity.** The existing backend suite
  is green at or above the measured base floor with 0 failed, the health
  payload vocabulary is byte-unchanged (`fallback_active` / `status` greps in
  `routers/health.py` and `schemas/health.py` still match the t41-pinned
  strings), `openapi.yaml` / `ops/` / `security/` / `observability/` /
  `frontend/` / `README.md` / `docs/` are byte-clean, and the only changed
  files are the four allow-listed ones. Delta purity is expressed against the
  immutable ref named in the card and declared non-appendable if it pins the
  branch base.

## Constraints (hard)

- Exactly 4 AUTHORED files: `backend/app/telemetry.py` (new),
  `backend/pyproject.toml`, `backend/app/main.py`,
  `backend/tests/unit/test_telemetry.py` (new). `backend/app/services/*` are
  t79's - touching them here is a card FAIL.
- **Generated-lockfile disclosure (measured, not hidden).** `backend/uv.lock`
  is TRACKED (`git ls-files backend | grep -i lock` -> `backend/uv.lock`), so
  adding a dependency necessarily changes a fifth path. The card admits
  `backend/uv.lock` as the ONE generated file in the delta, states that it is
  machine-written by `uv lock` / `uv sync` and never hand-edited, and reports
  its measured diff line count separately from the authored delta. This is
  declared as a known, disclosed exceedance of the warn-only `max_files: 4`
  ceiling (4 authored + 1 generated) rather than pretending the lockfile is
  unchanged - the alternative (committing a `pyproject.toml` whose lock does not
  match it) breaks every later card's `uv sync --offline` leg.
- **`openapi.yaml` is FROZEN.** `/metrics` is deliberately exempted from the
  contract, and the exemption is recorded IN THIS CARD'S TEXT (and repeated in
  the t88 report). It is NEVER recorded by editing `openapi.yaml`, by editing a
  contract-generated file, or by adding an allow-list entry to a gate. The card
  states the reason: the contract is the public API surface and `/metrics` is a
  loopback operational endpoint that is not part of the product API.
- **`/metrics` must be local-only and the mechanism must be named.** "It is
  behind a proxy" is not a mechanism. The card names the code-level gate, and
  ac3 proves both sides of it.
- The dependency addition is limited to the OTel SDK + Prometheus exporter
  packages (plus their transitive closure in `uv.lock`, which the builder
  regenerates and reports). No frontend dependency, no new dev-group tool.
- Additive behaviour only: no route change, no schema change, no migration, no
  change to the health payload, no change to any existing response body, no
  change to error handling. If the substrate cannot be wired without touching a
  create path, the wiring belongs in t79, not here.
- Performance/honesty: the card reports the measured pytest runtime delta if
  the substrate slows the suite, and never claims a production monitoring
  benefit it did not measure. Deferred/live-stack rows stay DEFERRED - a
  deferred row is never written as PASS (the phase_7 deferral discipline).
- mypy strict and ruff clean on the touched files; no `except Exception`;
  complete type annotations; 4-space indent; line length 100.
