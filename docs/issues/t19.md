## Goal

Ship the entire dashboard backend as one vertical slice: `dashboard_service.py`
holding the six REQ-BE-090..095 functions plus the REQ-BE-096 shared helpers,
`routers/dashboard.py` exposing the six GET endpoints under `/api/v1/dashboard`
with auth on every route, `schemas/dashboard.py` pinning the response shapes,
and the two frozen test files of REQ-TEST-017/023. This is the seventh router
appended to create_app (append-only; merged routers untouched). No model, no
migration, no new dependency.

## Acceptance criteria

- [ ] ac1 — Six GET endpoints exist at `/api/v1/dashboard/{summary,by-category,trend,cumulative,heatmap,recent}`, each requiring auth (401 contract shape without token) and returning exactly the REQ-API-060..065 key sets (groom pins byte-level key lists; money fields are 2-dp STRINGS, percentage is a number or null, never NaN/Infinity).
- [ ] ac2 — summary: empty month → total_spent "0.00", transaction_count 0, budget from the budgets row or "0.00" when absent, remaining, percentage NULL iff budget is 0, is_over_budget false; exactly-at-budget → percentage 100, is_over_budget false; over budget → is_over_budget true and remaining negative (REQ-BE-090, REQ-PROD-033 no-budget/exactly-at cases).
- [ ] ac3 — by-category: groups the caller's month expenses by category with category_id/name/color/amount/percentage, ordered amount DESC, percentages sum to ≤ 100 within rounding as pinned by groom; trend: last N months (default 6, max 24, 422 over max/invalid), months with zero expenses INCLUDED, year boundary walked correctly (REQ-BE-091/092).
- [ ] ac4 — cumulative: every day of the month present (28/29/30/31 incl. Feb leap), daily 0.00 on empty days, last cumulative equals the month total (REQ-PROD-033); heatmap: Monday-start weeks, exactly 7 days per week row, missing days 0-filled, max_amount correct, weeks default 12 max 52, crosses year boundary (REQ-BE-094); recent: date DESC then created_at DESC, limit default 10 max 50, caller-scoped items in the frozen expense 10-key shape (REQ-BE-095).
- [ ] ac5 — Python aggregation only (REQ-BE-092): no DB-specific date functions; helpers month_range/add_month/subtract_months/to_decimal exist in dashboard_service and are unit-tested; all arithmetic on Decimal, no float in the service path (grep gate).
- [ ] ac6 — Quality gates: backend suite green with zero regressions on the 184 merged tests, ruff + mypy strict clean, OpenAPI lists exactly the six new paths, no new Python dependency, no Alembic revision added (heads still 005), and the frozen-merged-test byte-identity holds.
