## Context

an unhelpful 422 because the colour field shows no type, no example and no
format, while the backend demands `#` plus exactly six hex digits. The fix is
UI-only: a native colour picker beside the text field, a `#RRGGBB` example
placeholder, a live swatch, a prefilled neutral default, a human-readable
format hint, and an icon example hint. The payload shape, the API, the schema
and the DB CHECK are untouched.

`category_pie_chart.test.tsx` asserts the slices carry the API colours.
