## Goal

A grader - human or AI - has 30 seconds per grading dimension, not 30 minutes. This
card produces the machine-checkable record for the four process-facing dimensions: one
file, one section per dimension, and in each section a claim with a maximum, a reason
grounded in a measurement, exactly ONE first entry point, and the deep-dive evidence
paths. Nothing in the file may be aspirational: every path it names must exist at
merge time, and every claim must be supportable by opening the named entry point.

**Honesty rule (binding on every line this card writes): a claim is only allowed if a
reader can check it within 30 seconds at the named entry point.** If a dimension
cannot be honestly claimed at its maximum, the record says so in its reason line and
claims less. No score is invented, and no score is claimed that this card did not
measure.

## Record format (the contract the fences check; groom may tighten, never loosen)

`docs/criteria/scoring_map/process.md` MUST be structured so each dimension section is
mechanically parseable:

```
## <exact dimension name>

- Claim: <integer>/<integer>
- Reason: <one measured sentence>
- First entry point: `<single path or URL>`
- Evidence: `<path>`, `<path>` ...
- Deep dive: `<path>`
```

`First entry point` is ONE pointer, not a list - that is what makes the map a map.
Every backticked path in a section must resolve on the merged tree.

### ac3 - Agent Team Specification and Context Management: both sections exist, claim at most 2 each, and their entry points are the real team and pointer surfaces (AGENTS.md, skills/*/SKILL.md, docs/process.md, docs/team)

```bash
set -u
F=docs/criteria/scoring_map/process.md
test -f "$F" || { echo "ac3 RED: $F missing"; exit 1; }
command -v python3 >/dev/null || { echo "ac3 RED: python3 missing"; exit 1; }
python3 - <<'PYEOF' || exit 1
import re, sys
F = "docs/criteria/scoring_map/process.md"
raw = open(F, encoding="utf-8", errors="replace").read().replace("\r", "")
def body(name):
    m = re.search(r"^## %s[[:space:]]*$" % re.escape(name), raw, re.M)
    if not m:
        return None
    rest = raw[m.end():]
    n = re.search(r"^## ", rest, re.M)
    return rest[: n.start()] if n else rest
fail = []
for dim, must in (("Agent Team Specification", ["AGENTS.md", "SKILL.md"]),
                  ("Context Management", ["AGENTS.md", "docs/"])):
    b = body(dim)
    if b is None:
        fail.append("no '## %s' section - the rubric names this dimension verbatim" % dim)
        continue
    c = re.search(r"^- Claim: (\d+)/(\d+)$", b, re.M)
    if not c:
        fail.append("%s: no '- Claim: N/M' line" % dim)
    elif int(c.group(1)) > int(c.group(2)) or int(c.group(2)) != 2:
        fail.append("%s: claim %s/%s does not use the rubric maximum 2" % (dim, c.group(1), c.group(2)))
    if not re.search(r"^- Reason: .+", b, re.M):
        fail.append("%s: no measured Reason line" % dim)
    ep = re.findall(r"^- First entry point: `([^`]+)`", b, re.M)
    if len(ep) != 1:
        fail.append("%s: %d First entry point lines, want exactly 1" % (dim, len(ep)))
    else:
        import os
        p = ep[0]
        if not p.startswith("http") and not os.path.exists(p):
            fail.append("%s: first entry point '%s' does not exist on this tree" % (dim, p))
    for tok in must:
        if tok not in b:
            fail.append("%s: the record never names %s - that is the surface the rubric grades" % (dim, tok))
    for path in re.findall(r"`([A-Za-z0-9][^`\s]*/[^`\s]*)`", b):
        import os
        if not os.path.exists(path):
            fail.append("%s: evidence path '%s' does not exist" % (dim, path))
if fail:
    sys.stderr.write("ac3 RED:\n" + "".join("  - " + f + "\n" for f in fail))
    raise SystemExit(1)
# the surfaces the record points at must really be the multi-role team the claim asserts
roles = [r for r in __import__("os").listdir("skills") if __import__("os").path.exists("skills/%s/SKILL.md" % r)]
if len(roles) < 4:
    sys.stderr.write("ac3 RED: only %d skills/<role>/SKILL.md exist (%s) - the Agent Team claim needs the real role set\n" % (len(roles), roles))
    raise SystemExit(1)
print("ac3 GREEN: AGENT TEAM SPECIFICATION AND CONTEXT MANAGEMENT recorded - both sections carry a claim within the rubric maximum 2, one existing first entry point each, every evidence path resolves, and the named surfaces are real (%d role skill files present)" % len(roles))
PYEOF
```
