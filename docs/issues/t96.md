## Goal

The Quick Start tells a first-time operator to copy an env file, and the very
comment above it says the step is optional because `check`, `setup:local` and
`vite` read no `.env`. A step in a run-it-now flow that the flow itself
describes as skippable is a defect: it is the step where a newcomer creates an
untracked file they may later commit. This card removes that step, renumbers the
sequence, and does the coordinated part - the stored gates that name the step in
the Quick Start sequence, and the one carried-gate replay whose sabotage victim
IS that line, all re-premised in the same handover, with the digest and
line-count pins moved. The `cp .env.example .env` line inside
`## Local verification in five minutes` (README:340) is a DIFFERENT, mandated
copy and stays exactly where it is.
