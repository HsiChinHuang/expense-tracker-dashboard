## Goal

Give a reviewer and an on-call engineer the visual half of the loop: a Grafana
dashboard file whose three panels answer the three questions the alert set
poses (is creation working, is it failing, is the database fallback active),
plus the collector configuration that t75 left commented - present as a
documented option, not as an enabled service.
