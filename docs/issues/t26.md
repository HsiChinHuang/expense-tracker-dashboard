## Goal

Ship the delivery pipeline as three GitHub Actions workflows, the Render
blueprint, and the Makefile completion: `ci.yml` (backend-test ∥
frontend-test → compose-build), `e2e.yml` (compose up + health wait +
Playwright + report artifact on failure + compose down, push-to-main only),
`deploy.yml` (fires on successful e2e run, POSTs the Render deploy hook from
the RENDER_DEPLOY_HOOK secret, polls /api/v1/health with retries, fails on
timeout), `render.yaml` (Docker web service on the free plan with
healthCheckPath and the REQ-CICD-032 env block + free PostgreSQL), the four
missing Makefile test targets, and the README deploy/cold-start/UptimeRobot
section. Per survey ruling 1 nothing here is EXECUTED (Actions cannot be
triggered from this harness, Render is unreachable): every AC is a hermetic
YAML/structural gate — js-yaml (already in root node_modules) parses each
workflow and asserts the pinned job/trigger/step structure — and each gate
is RED at base (workflows absent) and GREEN after.
