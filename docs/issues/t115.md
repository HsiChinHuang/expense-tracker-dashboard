## Goal

Three dimensions cover the run-the-thing story: metrics + traces + structured logs
sharing a trace ID for a key journey, collected, stored and viewable in a UI (0-2);
at least one alert that fires on user impact (0-1); and an agent that wakes on an alert
and fixes the issue (0-2). This card records the honest, measured position on all three.

These are the three dimensions where a scoring map is most tempted to over-claim,
because the project has a LOT of real observability machinery and two specific,
discoverable absences. The record states both halves:

- **What is real and measured:** four declared metric names with a single source of
  truth (`observability/alerts.yaml`, machine-readable
  `# # METRIC-INVENTORY:` line), a live `/metrics` exposition, JSON-structured logs
  with a frozen seventeen-event vocabulary and an explicit never-log list, a Prometheus
  + Alertmanager + Grafana local stack with a dashboard that visualises every declared
  name, **two alert rules**, and a **measured** incident drill
  (`incident-response/incidents/2026-10-17-db-fallback-01`) whose five artifacts exist
  on the tree.
- **What is not on the tree:** the OTel collector / Tempo / Loki block is **commented
  out and not enabled** (`observability/README.md`, "Optional traces and logs block"),
  so there are no traces and **no trace ID shared between metrics, logs and any span**;
  and the on-call responder is **read-only by policy** - `responder-task.md` says "You
  diagnose; a human operates. You must not attempt to fix anything", and
  `autonomy-policy.yaml` defaults to deny with `merge`, `restart_production` and
  `database_mutation` in `denied_actions`.

**Honesty rule (binding): a claim is allowed only if a reader can check it within 30
seconds at the named entry point.** This card therefore does not hard-code a
comfortable number: its fences **measure** whether traces and agent-side remediation
exist and reject a claim that exceeds what the tree proves. Where the answer is no, the
record claims below the maximum and prices the gap in one line. No score is invented.
