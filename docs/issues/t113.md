## Goal

Three dimensions decide whether the project is real: does the full stack run end to
end with a single command, do unit AND integration tests run with a single command and
pass, and does the whole system including the database come up through
Docker/Compose with a single command. This card records, for each, the claim, the
measured reason, ONE 30-second entry point, and the paths a grader opens next.

**Honesty rule (binding): a claim is allowed only if a reader can check it within 30
seconds at the named entry point.** Where a claim depends on running something, the
entry point is the command or the file that shows the command, and the reason line
names the measurement this card actually took. No score is invented.
