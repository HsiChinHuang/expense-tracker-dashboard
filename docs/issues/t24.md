## Goal

Ship the two container artifacts so the full stack is runnable by one
command on any machine that HAS a docker daemon: a two-stage `Dockerfile`
(node:20-alpine builds the Vite frontend; python:3.12-slim installs uv and
production backend deps, copies backend code + alembic, copies the built
frontend `dist` into the image's static directory, runs alembic upgrade head
then uvicorn as CMD, as a non-root user) and a `docker-compose.yml` with
exactly two services (`db`: postgres:16-alpine, healthcheck, named volume;
`app`: build context `.`, port 8000, depends_on db healthy, explicit env
including DATABASE_URL and CORS_ORIGINS, healthcheck against
/api/v1/health). Plus `.dockerignore` and the README local-modes section
(Mode A full docker, Mode B hybrid). Per survey ruling 1 every AC is verified
hermetically: YAML/structural gates parse the artifacts with the
already-installed parsers (PyYAML via the backend venv, js-yaml via root
node_modules) and assert the pinned structure; `docker build` is NOT an AC
command on this daemon-less host.
