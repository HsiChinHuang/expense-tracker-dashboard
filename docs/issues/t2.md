## Goal

Initialize the Vite + React + TypeScript frontend under `frontend/` with
Tailwind, Router, TanStack Query, Axios, and a Vitest/RTL test harness, plus a
minimal app shell, so `npm install`, `npm test`, and `npx tsc --noEmit` all
succeed.

## Acceptance criteria (draft)

- [ ] `frontend/package.json` pins versions for react, react-dom, react-router-dom, @tanstack/react-query, axios, tailwindcss, vitest, @testing-library/react, msw, eslint, prettier, typescript (REQ-TECH-081: versions pinned).
- [ ] `npm install` completes without error from `frontend/`.
- [ ] App shell renders via `frontend/src/main.tsx` mounted on a root route; Tailwind utility class visible in the shell markup.

- [ ] No runtime CSS-in-JS library present (REQ-TECH-003).
