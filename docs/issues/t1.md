## Goal

Initialize the FastAPI backend project under `backend/` with uv-managed
dependencies, a minimal app factory, a placeholder smoke test, and lint/type
configuration, so `uv sync`, `uv run pytest`, `ruff check .`, and
`uv run mypy .` all succeed.
