## Goal

Ship the expenses UI vertical: `pages/expenses_page.tsx` (month/category filters,
paginated table wired to t16 hooks with loading/empty/error states), the
create/edit `components/forms/expense_form.tsx` modal (RHF + Zod, blur
validation, backend field-error mapping, focus trap/restore, delete confirm
dialog via `components/ui/confirm_dialog.tsx`), and the
`context/toast_context.tsx` ToastProvider that finally pays the t9
carry-forward: a request that normalizes to `NETWORK_ERROR` surfaces a toast /
error state with a visible retry affordance instead of a silent dead table.

document title.
