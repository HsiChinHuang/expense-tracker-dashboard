## Goal

Ship the expenses UI vertical: `expenses_page.tsx` (month/category filters,
paginated table wired to t16 hooks with loading/empty/error states), the
create/edit `ExpenseForm` modal (RHF + Zod, blur validation, backend
field-error mapping, focus management, delete confirm dialog), and the
`ToastProvider` that finally pays the t9 carry-forward: a request that
normalizes to `NETWORK_ERROR` surfaces a toast with a visible retry affordance
instead of a silent dead table. Route `/expenses` wired into the merged
protected route tree with a unique document title.
