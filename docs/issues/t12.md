## Goal

Build the audit-writing machinery that t13/t14 integrate into their services:
the `AuditLog` model, Alembic revision `003` (table + three indexes), and
`backend/app/audit/logger.py` exposing a write helper that adds the audit row
to the CALLER's session/transaction (never commits independently), plus the
`get_client_ip` request dependency. This issue proves the atomicity contract
with a synthetic business write (a test-only helper or direct model write):
if the audit insert fails, the business write is rolled back. No expense or
budget endpoint is touched here, and no audit read endpoint is ever created
(FR-AUD-2).

## Acceptance criteria

- [ ] ac1 — `backend/app/models/audit_log.py` defines `AuditLog` matching REQ-DB-050 (Python-generated UUID PK, nullable `old_value`/`new_value`/`ip_address`) with both REQ-DB-051 CHECK constraints and the three REQ-DB-052 indexes; Alembic revision `003_*` (down_revision `002`) applies/downgrades cleanly on a fresh SQLite file; the JSON payload columns use the SQLAlchemy variant type so the same model works on SQLite (TEXT) and PostgreSQL (JSONB) (REQ-DB-054).
- [ ] ac2 — `write_audit(session, user_id, action, entity_type, entity_id, old, new, ip=None)` adds the row to the caller's session without committing; a test proves value shape: CREATE → `old_value` NULL and `new_value` populated; DELETE → inverse; UPDATE → both populated (REQ-DB-053).
- [ ] ac3 — Atomicity: a test forces the audit insert to fail (e.g. an invalid `action` value violating the CHECK, or monkeypatched raise) inside one session that already performed a business-model write, calls the single commit, and asserts BOTH writes are absent after rollback — the business row does not survive a failed audit write (REQ-DB-053, REQ-PROD-021, REQ-SEC-064).
- [ ] ac4 — `get_client_ip` dependency extracts the client IP (X-Forwarded-For first hop when present, else request.client.host) into a string ≤ 45 chars, unit-tested; no audit/log read endpoint exists anywhere: the app's `/openapi.json` contains no path containing "audit" (FR-AUD-2, REQ-PROD-015).
- [ ] ac5 — No regression and quality gates: full `uv run pytest` green (merged suite + new audit tests), `ruff check .` and strict `mypy .` exit 0; revision chain remains linear with a single Alembic head at `003`.
